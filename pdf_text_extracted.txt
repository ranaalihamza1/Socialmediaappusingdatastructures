A Social Media Feed System  is modern, high -scoring, easy to explain, and beautifully integrates 
multiple data structures like queues, stacks, linked lists, arrays, and sorting/searching algorithms. 
Social media platforms such as Twitter, Facebook, and Instagram rely heavily on dat a structures to 
efficiently handle post feeds, user interactions, and timelines . 
Students often don’t see how these real systems internally manage posts, search content, handle 
recent activity, or maintain undo/redo operations. 
This project implements a simplified but realistic social media feed using fundamental data structures 
to demonstrate how such platforms work under the hood. 
How the Project Works 
This system simulates a mini social media platform where users can: 
• Add posts 
• Delete posts 
• View feed in FIFO manner 
• Like posts 
• Search posts 
• Sort posts 
• Navigate feed with “Back” using a stack 
• Maintain friend lists using linked lists 
Detailed System Modules 
Module 1: User Management 
• Create account 
• View profile 
• Edit profile 
• Maintain friends list (linked list) 
Module 2: Post Management 
• Create post (enqueue) 
• Edit post 
• Delete post 
• Like/unlike post 
• Comment on post 
Module 3: Feed Management (Core DS Logic) 
Handles how the feed is built using: 
• Queue for new posts
